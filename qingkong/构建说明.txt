晴空天气 · 构建说明
====================

【应用简介】
全新设计的安卓天气应用（包名 com.qingkong.weather），数据来自和风天气。

功能：实时天气（动态天气场景动画背景 + 自绘矢量图标） / 24小时温度曲线 / 未来7·15天预报（含日出日落月相） / 城市搜索与定位 / 下拉刷新 / 天气动态渐变背景。

【数据接口】
可用接口（实测确认，其余接口已废弃或受限，勿添加）：
  /v7/weather/now    实时天气
  /v7/weather/24h    24小时预报
  /v7/weather/15d    15天预报（含日出日落/月相/紫外线）
不可用：空气质量 / 生活指数 / 天气预警（均已废弃或受限）

【和风天气配置】
API 密钥与专属域名写在 WeatherApi.java 顶部两个常量中，请自行替换为自己的密钥。
注意：该信息属于隐私，请勿提交到公开仓库。上传 GitHub 前请确认：
  - 不要上传 keystore/ 目录与 APK 文件（.gitignore 已配置排除）
  - 不要在 README 或说明文档中粘贴密钥与域名

【本机构建环境】
  Gradle : D:\android-build-env\gradle\gradle-8.7
  JDK    : D:\android-build-env\jdk\jdk-17.0.20.1+1
  SDK    : D:\android-sdk

【构建命令（PowerShell）】
  $env:JAVA_HOME = "D:\android-build-env\jdk\jdk-17.0.20.1+1"
  & "D:\android-build-env\gradle\gradle-8.7\bin\gradle.bat" -p "D:\桌面文件\a\QingKongWeather" assembleRelease

产物输出：app\build\outputs\apk\release\app-release.apk

【签名】
  keystore : keystore\qingkong.jks（本地私有，勿上传）
  配置      : gradle.properties 中的签名变量
  请妥善保管，后续升级版本必须用同一密钥签名，否则无法覆盖安装。

【版本升级】
  app/build.gradle 中 versionCode / versionName 递增后重新构建即可。
