Weather_API v2.6.1

稳定版安卓天气应用：实时天气、7天预报、天气预警，数据来自和风天气API

功能特点

🌍

全球天气查询

支持通过经纬度查询全球任何地点的实时天气和7天预报

🏙️

全国城市查询

内置全国主要城市数据库，支持城市名称和拼音查询

📊

详细天气信息

显示温度、体感温度、湿度、风速、气压、能见度、日出日落等信息

📅

7天天气预报

提供未来7天的天气预报，包括最高温、最低温和天气状况

💧

降水趋势图

以柱状图形式展示未来7天降水趋势，直观了解降雨情况

⚠️

天气预警

实时获取天气预警信息，有则显示无则隐藏，及时了解灾害天气

🔄

多次查询支持

支持连续多次查询，无需重新启动程序

⚙️

自定义城市

提供批处理工具，可自行添加新城市数据并重新编译

版本历史

📱 安卓版 2.6.1（稳定版） 2026-08-26
稳定版修复：
• 修复 APK 直接安装失败（补充缺失 drawable 资源）
• 移除计数限制功能
• 修复升级安装失败（下载校验APK有效性）
• 保持旧版 API Key 稳定
📱 安卓版 2.0（原生重制版） 2026-08-26
全新原生重制：
• 原生安卓应用，彩云天气风格UI，深色渐变背景随天气变化
• 实时天气：温度、体感、湿度、风况、气压、能见度、紫外线
• 新增24小时温度曲线图，逐时刻天气现象与降水概率
• 未来7天预报，含温度范围条可视化
• 天气预警横幅+详情弹窗，有效期内持续显示，每10分钟自动刷新
• 调用安卓定位权限，自动匹配定位到区县级
• 内置全国340+城市坐标库，支持搜索全国省/市/区县
• 支持手动输入经纬度坐标精确查询
📱 安卓版 1.0（经典版） 2026-07-16
经典版本：
• 安卓手机应用，支持城市和经纬度查询
• 实时天气、7天预报、天气预警展示
• 即原 Weather_API.apk
